# DongDong1226.github.io

스카이허브 인천 개발자 웹사이트 (공개 GitHub Pages, 주소 `https://dongdong1226.github.io/`).

- `index.html` — 게임 소개·Google Play 링크·개인정보처리방침·문의 (한·영)
- `app-ads.txt` — AdMob 판매자 확인 파일. **반드시 사이트 맨 위(루트)에 있어야 함** → `https://dongdong1226.github.io/app-ads.txt`
- `icon.png`·`shot-ko.jpg`·`shot-en.jpg` — 게임 저장소 `store/`의 아이콘·공항 스크린샷을 줄인 것

Play Console → 스토어 설정 → 연락처 '웹사이트'에 `https://dongdong1226.github.io` 를 넣어야 AdMob이 app-ads.txt를 찾음.
개인정보처리방침은 별도 저장소 `skyhub-privacy`.
